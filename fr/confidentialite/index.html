Politique de confidentialité

Dernière mise à jour : 11 novembre 2026.

Qui traite vos données

AL em Dia (alemdia.pt), Lisbonne, Portugal. Contact : privacidade@alemdia.pt.

Quelles données nous collectons

Uniquement ce que vous saisissez dans le formulaire : votre numéro de portable, votre email si vous l'indiquez, le numéro d'enregistrement de votre Alojamento Local si vous l'avez vérifié, et les options cochées. Nous conservons aussi la date et l'heure de l'envoi, la page d'où vous l'avez envoyé, le site d'où vous venez, le code du lien que nous vous avons envoyé si vous êtes arrivé par lui, la langue de la page et le temps passé sur la page, comme preuve de votre consentement et pour savoir comment vous nous avez trouvés.

La vérification du numéro d'enregistrement se fait dans votre navigateur, avec les données publiques du Registo Nacional de Alojamento Local. Si vous n'acceptez pas la mesure d'audience, le numéro saisi dans la case de vérification ne nous est pas envoyé, sauf si vous envoyez le formulaire. Si vous l'acceptez, il est enregistré (voir « Mesure d'audience »).

Pour quoi faire

Uniquement pour les finalités que vous cochez :

Contact par une société de gestion. Nous transmettons votre portable, votre email si vous l'avez indiqué, et le numéro d'enregistrement à une société de gestion de location saisonnière qui travaille dans votre zone, pour qu'elle vous contacte par téléphone ou WhatsApp et vous présente ses conditions. Base légale : votre consentement.

Suivi de la demande. Environ 30 jours après votre demande de contact, nous vous envoyons un seul message, par email ou WhatsApp, pour demander si la société vous a contacté et si vous avez signé un contrat. Répondre est facultatif. Base légale : notre intérêt légitime à savoir si le service a été rendu.

Alertes sur votre enregistrement. Nous vous envoyons des messages par WhatsApp ou email en cas de changement important concernant l'enregistrement de votre logement ou votre zone. Base légale : votre consentement.

Qui les reçoit

La société de gestion à qui nous vous présentons, seulement si vous avez coché cette option. Google, dont nous utilisons le service Google Sheets pour conserver les contacts et les données de mesure, et qui traite les données pour notre compte dans le cadre du Data Privacy Framework UE-États-Unis.

Combien de temps

Jusqu'au retrait de votre consentement ou jusqu'à ce qu'elles ne soient plus utiles aux finalités indiquées.

Vos droits

Vous pouvez retirer votre consentement à tout moment en répondant STOP à un message, en cliquant sur le lien en fin de chaque email ou en écrivant à privacidade@alemdia.pt. Vous pouvez aussi demander l'accès, la rectification, l'effacement ou la portabilité de vos données, ou vous opposer à leur traitement. Si vous estimez que vos droits n'ont pas été respectés, vous pouvez saisir la Comissão Nacional de Proteção de Dados (cnpd.pt).

Mesure d'audience

Seulement si vous cliquez sur « Accepter » dans l'avis de mesure, nous enregistrons : les pages vues, les clics, jusqu'où vous descendez dans la page, le temps passé, les champs du formulaire que vous touchez, les numéros d'enregistrement vérifiés, la langue, le fuseau horaire, la taille de l'écran et le type de navigateur.

Pour reconnaître votre navigateur lors d'une visite suivante, nous y conservons un identifiant aléatoire (stockage local du navigateur, équivalent à un cookie). Si vous êtes arrivé par un lien que nous vous avons envoyé, ce lien contient un code qui relie la visite au message envoyé, donc à vous. Un numéro d'enregistrement vérifié permet d'identifier le titulaire du logement dans les données publiques du RNAL.

Base légale : votre consentement. Vous pouvez modifier votre choix à tout moment dans « Mesure d'audience », en bas des pages de commune. Nous conservons ces données tant qu'elles sont utiles pour connaître l'utilisation du site.

Si vous avez reçu un message de notre part

Nous contactons des titulaires d'Alojamento Local à partir de données publiques : le Registo Nacional de Alojamento Local (dados.gov.pt) et les coordonnées que les sociétés et les titulaires publient sur internet. Nous utilisons le nom ou la raison sociale, le numéro fiscal, les numéros d'enregistrement et les coordonnées professionnelles, uniquement pour présenter AL em Dia. Base légale : notre intérêt légitime à faire connaître le service. Vous pouvez vous y opposer à tout moment en répondant STOP ou en écrivant à privacidade@alemdia.pt. Nous conservons ces données jusqu'à votre opposition ou jusqu'à ce qu'elles ne soient plus utiles à cette finalité.

Source des données publiques

Registo Nacional de Alojamento Local, Turismo de Portugal, publié sur dados.gov.pt (licence CC BY 4.0). Ce site n'est pas un service du Turismo de Portugal.
